CSS

Css é uma linguagem declarativa auxiliar a documentos html para stilização de definição de comportamento. O css pode ser declarado de três formas distintas

  1. Na tag style, definida no cabeçario de HTML;
  2. Em um documento externo por meio da tag link;
  3. Inline no proprio elemento HTML
  4. unica forma de comentar em CSS é usar /* */

CSS possui diversas formas de selecionar em quais elementoshtml uma regra será aplicada

Seletores:
  • seletor por elemento;
  • * seletor universal;
  • #id identificador unico;
  • .CLASSE OU CATEGORIA
